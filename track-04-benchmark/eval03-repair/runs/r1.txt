Looking at the five bug reports, I'll trace through the code to find the root causes:

**Bug 1 (Adjacency):** The `neighbors()` function has `for(let dx=-1;dx<1;dx++)` which only iterates -1 and 0, missing the +1 direction.

**Bug 2 (Overpowered workers):** The multiplier formula is `(0.7+0.15)*w.skill` = `0.85*skill`, but the tooltip shows `0.7+0.15*skill`. Should use the tooltip formula.

**Bug 3 (Phantom shortages):** In `endTurn()`, `runNeeds()` runs before `runProduction()`, but documented turn order has production first. Food/water hasn't been produced yet when we check for shortage.

**Bug 4 (Save/load broken):** `serialize()` excludes `eventsLast`, but `deserialize()` checks for it without initializing it first.

**Bug 5 (Departure timing):** The condition `c.zeroStreak>2` means colonists leave after 3 turns at zero morale, but the warning says "next turn" (should leave after 2 turns). Should be `>1` instead.
