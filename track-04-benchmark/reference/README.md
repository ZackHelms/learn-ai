# Frozen reference artifacts

Shared fixtures for the evals in this track. Everything in this directory is
**frozen**: never edited in place, only superseded by a new versioned file with
its own provenance entry. Consumers (eval02's game environment, eval03's
defect-seeding base) pin a version and a checksum, so a silent change here would
silently change two evals' scores.

change.
