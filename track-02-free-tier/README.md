# Track 02 — Free tier

> What can you actually do with the free tiers of the big AI platforms, without
> spending anything?

## The premise

Four platforms — Google Gemini, Microsoft Copilot, OpenAI ChatGPT/Codex, and
Anthropic Claude — each give away a real slice of capability for free. This
track walks through what that slice is on each of them, across three ways of
using them: the web, the desktop apps, and VSCode.

**Strictly zero spend.** Every exercise works without paying. Paid features
come up only as "here is what upgrading unlocks."

## Who this is for

You do not need a dev machine. If all you have is a phone, a tablet, or a
school computer, you can start here and get real experience with these tools.

It is also a useful breadth-first lap for developers — either before the depth
of [Track 01](../track-01-local-models/), or instead of it.
