# Track 03 — Claude Pro

> What does Claude Pro at $20/month actually unlock, compared to the free tier?

## The premise

Track 02 covers what the free tiers can do. This track is the natural
follow-up: you are paying for Claude Pro — or deciding whether to — and want to
know what that actually buys across the surfaces it covers, and how to use it
to level up specific AI skills.

## Who this is for

Someone already on Claude Pro who suspects they are using a tenth of it.

Some of this track will deliberately overlap with concepts from
[Track 01](../track-01-local-models/) — evals, SDK-based agents — because the
same ideas land differently when the model is strong, and that reinforcement is
the point.
